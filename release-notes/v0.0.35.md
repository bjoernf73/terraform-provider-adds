# v0.0.35

Adds an optional "must change password at next logon" flag to `adlc_user_password`.

## Added

- **`adlc_user_password` — `change_password_at_next_logon`.** Set it to `true` to force the
  user to choose a new password at their next logon (Active Directory's `pwdLastSet = 0`).
  This is useful for personal accounts: Terraform generates a strong initial password, you
  communicate it (for example by pushing `adlc_user_password.<name>.password` into Vault),
  and the user must replace it at first sign-in. The flag is fire-and-forget — AD clears it
  once the user changes the password, so the resource sets it when it sets the password and
  never reads it back or reconciles it, meaning it never drifts. It defaults to `false`, so
  automation accounts that keep using the stored password are unaffected. It cannot be
  combined with `adlc_user.password_never_expires` or `cannot_change_password` on the same
  account, which Active Directory rejects.

# v0.0.32

The new `adlc_backup_gpo_export` data source exports any live GPO as a native GPMC
backup, including GPOs originally imported from JSON. Verified against the Defender
STIG GPO under both Windows PowerShell and PowerShell 7; the default remains
`powershell.exe`.

## Added

- **`adlc_backup_gpo_export` data source.** Runs `Backup-GPO` on the remote host and
  returns the source GPO GUID, snapshot GUID, and a sensitive map of relative file paths
  to base64 contents. Persist the result with `local_sensitive_file` and `content_base64`
  for later use with `adlc_backup_gpo`. Remote temporary files are removed after export;
  each read creates a new snapshot with new timestamps and a new backup GUID. Native
  backup layout is preserved, including root catalog files such as `manifest.xml`.

## Fixed

- **`adlc_group`: unrelated updates no longer make `distinguished_name` and `managed_by_dn`
  unknown.** Previously, changes such as `manager_can_update_membership` forced resources
  referencing `distinguished_name` in a replace-only argument, such as `adlc_access_rule.target`,
  to be replaced. These values now become unknown only when `name`/`path` or `managed_by` change.
- **`adlc_group`: clarified `manager_can_update_membership` ownership.** The setting is an
  explicit Allow `WriteProperty` ACE on `member` for the `managed_by` principal. Its default,
  `false`, removes that ACE. Set it to `true` instead of creating the same ACE with
  `adlc_access_rule`; managing it in both places causes a perpetual diff.

## Documentation

- Added a dedicated backup-export data source reference and a file-persistence example.
- Updated the GPO guide and `gpo_powershell_path` description to distinguish module-based
  operations from LDAP-only GPO reads and links.

## Internal

- Added local backup-export tests for binary file contents, domain-controller forwarding,
  missing GPOs, and cleanup on success/failure, plus an opt-in live probe gated by
  `ADLC_HOST` and `ADLC_BACKUP_GPO_EXPORT_NAME`.
- Added backup export assertions to e2e and showcase, including the Defender STIG GPO
  that showcase imports through `adlc_json_gpo`.
